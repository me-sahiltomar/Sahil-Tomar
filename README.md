## 3. Technical Architecture

- **Framework:** Next.js 14 / 15 App Router
- **Language:** TypeScript (strict mode, zero build warnings)
- **Styling:** Tailwind CSS (crisp light mode with `#FFFFFF` surfaces, `#FAFAFA` page background, `#09090B` text, `#71717A` muted text, `#E4E4E7` borders, and high-contrast dark callouts)
- **Icons:** Lucide React
- **Status Micro-Badges:** Emerald (`ACTIVE`), Amber (`BETA`), Slate (`ARCHIVED` / `CASE STUDY`)
- **Typography:** Inter (headings & body), JetBrains Mono (section eyebrows, tech stack, and metadata)
- **Accessibility:** Skip-to-content bypass, WCAG AAA focus-visible ring (`outline: 2px solid #09090b`), full ARIA modal dialog semantics with keyboard trap and scroll locking.
